# 个人工作台

用于管理工作与生活记录的单页工作台，支持电脑和手机浏览器使用。页面代码、样式及交互集中在 [`index.html`](./index.html) 中，无需构建即可打开。

## 快速使用

本地验证：用 Edge 或 Chrome 打开 `index.html`。修改文件后刷新页面即可查看效果。

GitHub 发布：将 `index.html` 和本文件放在仓库的同一目录，将该目录用作 GitHub Pages 的发布来源。README 会显示在仓库页面，工作台由 `index.html` 提供。

已有站点：[打开个人工作台](https://j2pm8zdjr9-maker.github.io/xjjgzhang/)。本说明不表示最新本地修改已经发布到该站点。

## 主要功能

| 分类 | 功能 |
| --- | --- |
| 工作 | 待办任务、工作留痕、日程、纪检监察相关记录 |
| 学习与文化 | 备考、影剧书记录、阅读及观看日志 |
| 健康与生活 | 身体管理、饮水、打卡、日记、宝宝成长 |
| 家庭与资产 | 财务、车辆、物品、家人和宠物档案 |
| 汇总与设置 | 首页总览、时光档案、主题与字号、数据备份 |

### 影剧书记录

- 封面墙每行固定三个封面；长标题和分类换行，评分独立排列。
- 点击封面进入详情，可编辑、删除，以及将未结束的作品标记为“看完”或“弃了”。
- 电影：记录观看日期和时长。
- 电视剧：记录观看日期、集数和时长。集数可填写“第3集”“第3—5集”或“第2季第1集”。
- 书籍：记录阅读日期、起止页码和时长。
- 历史阅读/观看日志继续保留；旧电视剧日志缺少集数时显示“未记录集数”。

### 时光档案

- 同一天、通过来源任务编号明确关联的任务与工作留痕合并展示，原始记录保留。
- 同名但没有关联、或不同日期的记录不自动合并。
- 任务仅展示已完成项，隐藏待办和进行中任务及其关联留痕。
- 未来日期的工作留痕、未完成的学习计划不展示。
- 身体测量使用中文名称及单位，例如“体重 80.45 公斤”。

## 数据与备份

业务数据保存在当前设备的浏览器本地存储中。GitHub 存放页面代码，不会自动同步电脑和手机的个人记录。本地文件页面与 GitHub Pages 页面也使用各自的浏览器存储。

请使用设置中的导出功能备份业务数据。源码文件或 GitHub 提交历史不能代替个人数据备份；不要把包含个人记录的 JSON 备份提交到公开仓库。

**当前目录版本的导入操作会覆盖全部本地数据。** 导入前先导出当前数据。本说明按当前 `index.html` 核对：其中未包含此前另一份版本的智能合并实现，不能将普通导入当作双端合并使用。

## 在电脑上检查手机显示

1. 在 Edge / Chrome 打开本地 `index.html`，按 F12，再按 Ctrl + Shift + M。
2. 使用响应式设备模式，分别检查 320、390、430 像素宽度。
3. 用长标题、长分类和多条日志检查封面墙、列表和详情弹窗。
4. 调大工作台字号，确认三个封面仍在同一行，文字、评分和操作按钮完整可见。
5. 检查分页、弹窗底部按钮，以及是否存在异常横向滚动。

模拟器能发现多数布局问题，正式发布前仍应在实体手机检查一次。测试数据应与日常业务数据分开。
