# 电车管理 · 电池健康（充电周期模型）改动说明

本次按「以充电为周期、逐次记录行程」的思路重写电车管理的电池健康功能，并**移除了原来的「充电 / 里程」切换 pill，仅保留充电记录列表**。

## 核心模型

把每一次充电当成一个**周期**：

- 充电记录（周期边界）：充电前电量%、充电后电量%、电表度数、充电前总里程。
- 每个周期内逐次记录**行程**（像读书标记进度）：本次里程 km + 本次耗电 kWh（车机/仪表显示）。

当存在**相邻两次充电**时，即可闭合一个周期、推算电池健康：

```
上次行驶电量%  = 本周期充电后% − 下次充电前%
本周期耗电      = Σ(本周期各次行程耗电)        // 车机电池侧，免充电效率
实际容量        = 本周期耗电 ÷ (上次行驶电量% ÷ 100)
电池健康度 SOH  = 实际容量 ÷ 标称容量
```

> 关键点：容量/健康度**只用车机逐次行程耗电 + 两次充电的电量%差**推算，**不依赖也不受充电效率影响**（电表度数仅用于充电成本/损耗统计）。

## 你的使用流程（示例）

1. 第一次充电：记 `充电前 28% → 充电后 80%`、电表 `37.92`、充电前里程 `26185`。
2. 展开这条充电记录，点「**+ 记一笔行程**」，逐次填 `里程 + 耗电`（如 34.4 km / 6.8 度）。
3. 第二次充电：记 `充电前 41% → …`。此时上一周期被闭合：`上次行驶电量% = 80 − 41 = 39%`，结合你记的行程耗电，自动算出实际容量与健康度。
4. 多记几对充电，健康度按各有效周期**汇总平均**（容量 = Σ耗电 ÷ Σ电量%，权重为消耗的电量%）。

## 默认容量

- 未标定时按出厂容量 **45.15 度**计算（`sohNominal`）。
- 已在「⚙️ 电车配置与保养」里改过电池容量，则视为已标定，SOH 用它做分母。

## 漏记提醒

- 每个闭合周期会比较「**下次充电前里程 − 本周期充电前里程**」与「**本周期各次行程里程之和**」。
- 偏差 > `max(3 km, 本周期里程 5%)` 时，在该充电明细与电池健康卡顶部给出 ⚠️ 提醒：可能漏记了某次行程，数据已计入统计但建议核对。

## 与上一版的区别

| 项 | 上一版（里程/充电双列表） | 本版（充电周期） |
|---|---|---|
| 列表 | 充电 / 里程 两个 pill 切换 | 仅充电记录，行程挂在每条充电内 |
| 健康度来源 | 单条里程 `能耗 ÷ 电量下降%`（易因小 ΔSoC 放大误差） | 相邻两次充电间「Σ行程能耗 ÷ 消耗电量%」（免充电效率，多周期汇总） |
| 里程记录 | 独立的「里程记录」列表 | 每个充电周期内「逐次行程」，像读书标记 |
| 标称容量 | 默认 45 | 默认 45.15 |
